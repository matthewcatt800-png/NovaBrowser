# NovaBrowser

A lightweight custom web browser for Android.

## Overview
NovaBrowser is an Android browser project focused on a straightforward browsing experience and a compact app footprint.

## Project
- Platform: Android
- Language: Java

## Getting started
1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle and build the application.
4. Install the resulting APK on a compatible Android device for testing.

If a prebuilt APK is present in the repository, check its filename and release notes before installing it.

## Notes
Browser security and compatibility depend on the Android WebView version and the implementation in this repository. Keep WebView and Android components up to date.
